# godot_urdf integration

This directory is a maintained Metis fork of
[brean/godot_urdf](https://codeberg.org/brean/godot_urdf), distributed under
the BSD 3-Clause license in `LICENSE`.

Metis carries local support for URDF `mimic` joints, project-local `res://`
paths, bounded joint control and the runtime behavior exercised by the XArm
tests. Do not replace this directory with an unmodified upstream archive.
