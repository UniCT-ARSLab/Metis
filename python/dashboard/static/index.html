Reward (raw / avg 50 / max 50 / best) iPer-episode return. With asynchronous multi-env collection every point is ONE env's episode (one agent here), interleaved across the 8 envs — so the raw line is noisy by design. avg 50 is the moving average over the last 50 completed episodes (the trend to follow); max 50 is the highest return within the last 50 episodes — the RECENT peak, which can go down (unlike best) so a one-off high does not hide a later decline; best is the running maximum return so far (the all-time ceiling, never decreases). The absolute scale and sign are task-specific, so a negative return does not automatically mean learning failed. For the cleanest signal use the frozen-eval reward_mean (every 100 episodes), not this live stream.

Frozen policy evaluation iSuccess measured periodically in an isolated deterministic run of a saved checkpoint. Regular success excludes bootstrap or assisted reset modes when the scenario reports them and is used for curriculum promotion and policy selection. Overall success includes every evaluation episode. These sparse points are the appropriate measure of deployed policy quality.
